# Kestrel Studio

Independent open-source engineering studio focused on **Rust / Soroban**, **TypeScript / Next.js**, **Go**, **Python**, and **Solidity (Foundry)**.

### Focus Areas
- **Protocol & Smart Contract Testing**: Unit, fuzz, and mainnet/testnet fork suites (`Foundry`, `cargo test`, `soroban-sdk`).
- **Backend & API Reliability**: Webhook filtering, observability, strict config validation, and regression tests (`TypeScript`, `Node.js`, `Rust`, `Go`).
- **Frontend & Documentation**: Accessible React/Next.js UI components, SEO metadata, and reproducible developer docs.
